在线视频播放器

🎬 在线视频播放工具

这是一个基于腾讯云播放器SDK开发的在线视频播放工具，支持多种视频格式的在线播放，包括：

  • M3U8/HLS格式 - HTTP Live Streaming流媒体
  • MP4格式 - 标准视频文件
  • FLV格式 - Flash视频格式
  • 其他格式 - 浏览器支持的视频格式

📱 使用方法

  1. 在输入框中粘贴视频播放地址
  2. 点击播放按钮开始观看
  3. 支持播放控制：播放/暂停、音量调节、全屏等
  4. 支持清晰度切换和播放速度调节

⚠️ 注意事项

  • 请确保视频地址有效且可访问
  • 建议使用HTTPS协议的视频地址
  • 部分视频可能需要特定的播放权限
  • 如遇到播放问题，请检查网络连接和视频格式
